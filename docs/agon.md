# Агон

Модуль для VTT по системе **AGON 2nd Edition** («Агон», John Harper &
Sean Nittner, Evil Hat; русское издание — Студия 101).

## `agon-sheet` — лист героя

Бланк — `sheet.png` (отрисовка PDF-страницы). Поверх него прозрачно
наложены поля, поэтому лист выглядит как бумажный, но заполняется в VTT.

### Несколько героев

- В модуле можно создать **сколько угодно листов** (кнопка «＋ Новый») и
  удалить текущий («Удалить»). Пустой список не остаётся: вместо последнего
  удалённого создаётся новый чистый лист.
- Список героев и все правки хранятся в общем состоянии сессии
  (`extensionState['agon-sheet']`), поэтому их видят Мастер и все игроки.
- У каждого участника **свой выбранный лист**: переключение в списке не
  переключает остальных. Выбор запоминается в `localStorage` клиента
  (`vtt.ext.selection:agon-sheet`).
- Правки разных листов объединяются по `id` (`mergeWithBaseline`): если двое
  одновременно заполняют разные листы, изменения не затирают друг друга.
- Редактировать может любой участник: у модуля `playerWritable: true`,
  запись игроков проверяется на сервере.

### Поля

- **Текст** — эпитет, имя, «из рода», покровитель и способность,
  обязательства, облик и особенности, подвиги и добыча, добродетели.
  Поля ограничены областью бланка, поэтому текст не «разъезжается» по
  соседним блокам.
- **Кубики** — выпадающие списки `4 / 6 / 8 / 10 / 12` для эпитета, имени и
  четырёх Доменов. Значение по умолчанию — `6`.
- **Чекбоксы**:
  - Слава — 40 клеток;
  - Имя — 6 рубежей (40, 80, 120, 160, 200, 240); при отметке любого рубежа
    шкала Славы очищается;
  - Пафос (5), Агония (1), Судьба (12);
  - Подвиги (13) и Награды (8);
  - Милость богов — 24 белых ромба, по две метки на каждого бога;
  - два ромба у «Способности» — узы с покровителем.
- **Портрет** — весь большой круг на бланке кликабелен. Нажмите на него
  (или перетащите файл), выберите изображение — оно обрежется по кругу и
  сохранится в общем состоянии. При наведении доступны «Заменить» и «×».
  Изображение сжимается до 512 px по длинной стороне, чтобы JSON сессии
  оставался компактным.

### Окно

Лист открывается только через `CharacterSheetFrame`:
масштаб 50–200 % (`− / % / +`), изменение размера окна, запоминание
масштаба и размера отдельно для Мастера и игрока. Внутри iframe нет
собственных кнопок масштаба.

## Формат состояния

```jsonc
{
  "currentId": "agon_…",
  "chars": [
    {
      "id": "agon_…",
      "fields": {
        "name": "Адраст",
        "epithetDie": "6",
        "glory1": false,
        "favor1": true,
        "portrait": "data:image/jpeg;base64,…"
      }
    }
  ]
}
```

Старые локальные значения (`agon-sheet-fields-v1`) переносятся в первый
лист при первом открытии и больше не используются.

## Ограничения

- Нет автоматических бросков/состязаний и битв — это следующие модули.
- Портрет хранится в JSON сессии (data URL), а не отдельным файлом, чтобы
  игроки могли загружать его без доступа к файловой системе Мастера.
