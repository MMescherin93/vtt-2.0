# Несколько карт в сессии

Статус: **реализовано** (вариант A). Решения зафиксированы ниже.

## Принятые решения

- Карты выкладываются **слева направо на общем полотне**.
- Зазор между картами — **120 px** пустого тёмного поля (`MAP_GAP`).
- Переключение между картами — **панорамирование полотна** (перетаскивание).
- **Без лимитов** на количество карт.
- Токены можно **перетаскивать между картами**.
- Туман войны и рисунки — **общие на весь мир**, координаты сквозные.

## Как устроено

1. **Данные.** `Session.maps: MapAsset[]`, `MapAsset = { id, imageUrl, width, height }`.
   Схема `schemaVersion: 2`. Старая сессия с `map` мигрирует в `maps` при загрузке
   (`normalizeSession`), файл перезаписывается уже в новом формате.
2. **Раскладка.** `layoutMaps()` в `shared/utils/maps.ts`:
   `x` следующей карты = сумма ширин + зазор × (n−1), высота мира = максимальная высота.
   Утилиты: `MAP_GAP`, `layoutMaps`, `worldSize`, `worldCenter`.
3. **Канвас.** `Board` считает поле по миру; `MapLayer` рисует все карты по смещениям,
   зазоры — тёмный фон полотна. Сетка, туман и рисунки работают в координатах мира.
4. **Туман.** Переведён на векторные фигуры Konva (`Rect`/`Line` + `destination-out`)
   вместо offscreen-канвы: широкое полотно больше не съедает память.
5. **Токены.** Ограничиваются размерами мира, поэтому переносятся между картами.
6. **Панель «Карта и сетка».** Список карт с размерами и удалением, кнопка добавления,
   «убрать все». Подсказка про зазор и переключение перетаскиванием.
7. **Камера.** Вписывается по всему миру; позиция сохраняется локально, как раньше.

## Проверки

Интеграционный тест (`npm run test:server`) проверяет:

- миграцию v1 → v2 (одна карта → `maps`);
- раскладку с зазором 120 px и размер мира;
- отдачу файлов карт по HTTP.

## Возможные развития

- Мини-индикатор карт с переходом по клику.
- Перестановка карт местами и настройка зазора.
- Изоляция сцены на карту (вариант B) — потребует `mapId` у токенов/тумана/рисунков.
