# Клинки во тьме

Материалы и модули для Blades in the Dark на основе бесплатных раздаточных
материалов «Станции „Ролевая“»:

- [страница системы](https://rpgbook.ru/STBITD01?search=клинки%20во%20тьме&description=true)
- [раздел «Клинки во тьме»](https://rpgbook.ru/settings/bitd)

## Модули

### `bitd-sheets` — бланки персонажей

Один модуль объединяет все доступные PDF-бланки персонажей:

- пустой бланк;
- Артист;
- Вампир;
- Ищейка;
- Кукловод;
- Мистик;
- Призрак;
- Проныра;
- Умелец.

В панели есть выбор персонажа, просмотр PDF через PDF.js, переход по страницам,
масштаб и режим «По ширине». Выбор запоминается локально у клиента.
Окно использует обязательный `CharacterSheetFrame` (масштаб 50–200% и
изменяемый размер).

### `bitd-crews` — бланки команд

Один модуль объединяет все доступные PDF-бланки команд:

- пустой бланк команды;
- Адепты;
- Бандиты;
- Барыги;
- Душегубы;
- Перевозчики;
- Тени.

Устроен так же: выбор команды, PDF.js, страницы, масштаб, локальное запоминание
выбора.

## Файлы

PDF лежат локально в `desktop-host/extensions/bitd-sheets/pdfs` и
`desktop-host/extensions/bitd-crews/pdfs`. Это бесплатные раздаточные материалы
с указанного ресурса; не публиковать их отдельно как собственный арт-пакет.
