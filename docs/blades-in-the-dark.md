# Клинки во тьме

Материалы и модули для Blades in the Dark на основе бесплатных раздаточных
материалов «Станции „Ролевая“»:

- [страница системы](https://rpgbook.ru/STBITD01?search=клинки%20во%20тьме&description=true)
- [раздел «Клинки во тьме»](https://rpgbook.ru/settings/bitd)

## Модули

### `bitd-sheets` — бланк персонажа

Оставлен только **пустой бланк персонажа**. Поверх PDF наложены поля:

- строки для имени, команды, клички, внешности и заметок;
- строки характеристик, действий, друзей, предметов и опыта;
- чекбоксы и трекеры, которые есть на пустом бланке.

Поля редактируются прямо в окне и сохраняются локально у клиента. PDF
отображается через локальный PDF.js, есть переход по страницам, масштаб и
«По ширине». Окно использует обязательный `CharacterSheetFrame`.

### `bitd-crews` — бланк команды

Оставлен только **пустой бланк команды** (две страницы). На обе страницы
наложены редактируемые поля и чекбоксы для названия, репутации, территории,
контроля, талантов, опыта команды, знакомых, улучшений, тюрьмы и остальных
разделов бланка.

Выбор типа убран: модуль открывает один пустой бланк. Значения полей
сохраняются локально.

## Файлы

Пустые PDF лежат в `desktop-host/extensions/bitd-sheets/pdfs/empty.pdf` и
`desktop-host/extensions/bitd-crews/pdfs/empty.pdf`. Это бесплатные
раздаточные материалы с указанного ресурса; не публиковать их отдельно как
собственный арт-пакет.
