# Корни (Root RPG)

Модули для **Root: The Roleplaying Game** (Magpie Games, по миру Leder Games).
Русская локализация — «Корни» (CrowdGames / Pandora’s Box Studio).

## Что уже есть

### `root-sheet` — листы бродяг

- несколько листов в одном модуле: селектор «Лист», «＋ Новый», «Удалить»;
- имя, архетип, вид, местоимения, внешность, мотив, характер;
- пять характеристик: **Шарм, Хитрость, Сноровка, Удача, Мощь**;
- три трека вреда по пять отметок: **Травмы, Истощение, Затраты**;
- репутация: **Обитатели, Маркиса де Коте, Крылатые династии, Лесной союз**;
- ходы, связи, снаряжение;
- вопросы предыстории и заметки;
- броски 2d6 + характеристика прямо с листа, результат уходит в общий чат.

**Доступ игроков.** Включённость модуля общая для сессии: Мастер включает
`root-sheet` в панели «Расширения», после чего иконка листа появляется в доке
у всех участников. Листы общие: игроки видят и могут редактировать все листы
(`playerWritable`). При этом **у каждого клиента свой выбранный лист**:
переключение не переключает остальных, а правки разных листов объединяются.
Состояние лежит в `extensionState['root-sheet']` в формате
`{ version: 2, currentId, chars: [{ id, fields }] }`.

Старые одиночные листы (`root-sheet-v1`) при открытии автоматически
превращаются в первый лист нового формата; старые названия архетипов и два
трека (`harm`/`depletion`) мигрируют в новые поля.

### `root-roll` — броски

- 2d6 + выбранная характеристика;
- 10+ / 7–9 / 6−;
- преимущество и помеха (3d6, оставить две лучшие/худшие);
- модификатор;
- результат отправляется в чат.

### `root-moves` — библиотека ходов

- категории: базовые, оружейные, дорожные, сессионные, репутационные,
  архетипы, свои;
- поиск по названию и тексту;
- создание и редактирование ходов;
- выбор характеристики для броска;
- кнопка «Бросить» с отправкой в чат;
- кнопка «В лист» — добавляет ход в **текущий выбранный** лист;
- импорт и экспорт JSON.

Библиотека общая для стола и не содержит текстов книги: ходы добавляются
вручную или импортируются.

## Ограничения

- Тексты архетипов и ходов не встроены: используйте свои книги и материалы.
- Нет отдельного компендиума, листа поляны и отряда — это следующие модули.
- Треки вреда пока не привязаны к токенам: это лист, а не трекер NPC.

## Следующие шаги

1. `root-clearing` — лист поляны.
2. `root-party` — отряд, связи и общая репутация.
3. `root-travel` — путешествия и ходы фракций.
4. `root-npc` — карточки NPC и фракций.
