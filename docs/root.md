# Корни (Root RPG)

Модули для **Root: The Roleplaying Game** (Magpie Games, по миру Leder Games).

## Что уже есть

### `root-sheet` — лист персонажа

- имя, плейбук, вид, местоимения, внешность;
- стремление и натура;
- пять характеристик: Обаяние, Хитрость, Ловкость, Удача, Мощь;
- Урон и Истощение — по четыре отметки;
- Репутация с Маркизой, Династиями Скопа и Лесным союзом;
- ходы, связи, снаряжение;
- вопросы предыстории и заметки;
- броски 2d6 + характеристика прямо с листа, результат уходит в чат.

Состояние общее для стола: Мастер и игроки видят один лист. Игроки могут
редактировать его (`playerWritable`), данные хранятся в
`extensionState['root-sheet']`.

### `root-roll` — броски

- 2d6 + выбранная характеристика;
- 10+ / 7–9 / 6−;
- преимущество и помеха (3d6, оставить две лучшие/худшие);
- модификатор;
- результат отправляется в чат.

### `root-moves` — библиотека ходов

- категории: базовые, оружейные, дорожные, сессионные, репутационные, плейбуки, свои;
- поиск по названию и тексту;
- создание и редактирование ходов;
- выбор характеристики для броска;
- кнопка «Бросить» с отправкой в чат;
- кнопка «В лист» — добавляет ход в лист персонажа;
- импорт и экспорт JSON.

Библиотека общая для стола и не содержит текстов книги: ходы добавляются
вручную или импортируются.

## Ограничения

- Тексты плейбуков и ходов не встроены: используйте свои книги и материалы.
- Нет отдельного компендиума и листа clearing — это следующие модули.

## Следующие шаги

1. `root-clearing` — лист поселения.
2. `root-party` — отряд, связи и общая репутация.
3. `root-travel` — путешествия и ходы фракций.
4. `root-npc` — карточки NPC и фракций.
