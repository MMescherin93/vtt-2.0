# Запретные земли (Forbidden Lands) — идеи модулей

Статус: **лист персонажа и кубы реализованы** (`forbidden-lands-sheet`,
`fl-dice`); инициатива, путешествия и укрепление пока в бэклоге. Документ
фиксирует исследование, механику, архитектуру и порядок работ.

## 1. Цель

Добавить в VTT поддержку системы **Forbidden Lands / «Запретные земли»**
(Year Zero Engine, Free League) отдельным разделом каталога расширений:

- кастомные кубы (базовые/навыка/снаряжения, успехи и баны, push);
- лист персонажа;
- карточная инициатива;
- по желанию — путешествия, укрепление, партия.

Система заметно отличается от «Тройки» и AZAG: здесь нет HP в привычном виде,
урон снижает атрибуты, а ключевая механика — пул d6 с перебрасыванием (push).

## 3. Механика, которую надо поддержать

### 3.1. Броски

Пул d6 трёх типов:

| Тип        | Цвет    | Источник          |
| ---------- | ------- | ----------------- |
| Базовые    | белые   | значение атрибута |
| Навыка     | красные | уровень навыка    |
| Снаряжения | чёрные  | бонус предмета    |

- **6** — успех, **1** — бан.
- Модификаторы меняют только кубы навыка: плюс добавляет красные,
  минус добавляет «минус-кубы», чьи 6 вычитаются из успехов.
- Помощь: +1 куб за помощника, максимум +3.
- Противопоставленный бросок: побеждает больше успехов; пушить может только
  атакующий. Уклонение и парирование — не opposed, их можно пушить.
- Гордость (Pride): раз за сессию d12, добавляется к броску; после неё пушить
  нельзя. Точную интерпретацию d12 уточнить по книге (см. открытые вопросы).

### 3.2. Push (толчок)

- Один раз за бросок.
- Перебрасываются все кубы, кроме **1** и **6**.
- После push:
  - **1 на белых** — 1 урон соответствующему атрибуту и **+1 Воля** за каждый;
  - **1 на чёрных** — бонус снаряжения −1; при 0 предмет ломается;
  - **1 на красных** — без последствий.
- Урон и Воля применяются к листу персонажа, а не к абстрактному HP.

### 3.3. Атрибуты и состояние

- **Сила (Strength)**, **Ловкость (Agility)**, **Смекалка (Wits)**,
  **Эмпатия (Empathy)**.
- У атрибута есть текущее и максимальное значение; ноль — «Сломлен» (broken).
- **Воля (Willpower)** — отдельный счётчик; тратится на таланты и заклинания,
  приходит с push.
- **Состояния:** сонный, голодный, жаждущий, замёрзший.
- Критические ранения — отдельный список с временем лечения.
- Опциональный вариант Foundry: Health/Resolve вместо урона атрибутов —
  можно добавить позже как настройку.

### 3.4. Навыки (16)

| Атрибут  | Навыки                                                 |
| -------- | ------------------------------------------------------ |
| Сила     | Мощь, Выносливость, Ближний бой, Ремесло               |
| Ловкость | Скрытность, Движение, Стрельба, Ловкость рук           |
| Смекалка | Разведка, Знания, Выживание, Проницательность          |
| Эмпатия  | Убеждение, Выступление, Обращение с животными, Лечение |

Названия — рабочий русский перевод, можно заменить на официальную локализацию.

### 3.5. Бой

- Инициатива — **карты 1–10**, первым ходит меньшая; в начале раунда карты
  можно обменять; на новый раунд — новая раздача.
- За ход: одно медленное + одно быстрое действие **или** два быстрых.
- Дистанции: Arm’s Length / Near / Short / Long / Distant; зоны, укрытия,
  темнота.
- Оружие: хват, бонус, урон, дистанция, свойства.
- Броня: рейтинг, щит, поломка при банах.
- Урон снижает атрибуты; критические ранения; «Сломлен».

### 3.6. Путешествия

- Гекс-краул; активности по четвертям дня: Hike, Lead the Way, Keep Watch,
  Forage, Hunt, Fish, Make Camp, Rest, Sleep, Explore.
- Модификаторы местности и погоды, припасы/вода, случайные встречи.
- Отдельный крупный модуль, не часть листа.

### 3.7. Укрепление

- Здания, наймиты, материалы, доход/расход, зарплаты.
- Общий объект партии.

## 4. Архитектура в VTT

- Новый раздел каталога: `forbidden-lands` в `EXTENSION_CATEGORIES`.
- Модули — обычные расширения с `category: 'forbidden-lands'`.
- Дайс-движок — **чистые функции** в `shared/utils/flDice.ts`, чтобы его
  использовали и панель, и лист, и тесты.
- Лист — нативная React-панель (не iframe): нужны вычисления, кнопки бросков,
  применение последствий.
- Состояние листа — `Session.extensionState['fl-sheet']`:
  `{ currentId, chars: FlCharacter[] }`, `playerWritable: true`.
- У каждого клиента свой текущий лист; правки разных листов сливаются по id
  (механизм `perClientSelection` + `mergeListKey` уже есть).
- Результаты бросков — в общий чат через `sendChat` (хост) / `publish` (игрок).
- Инициатива картами — либо отдельный модуль, либо режим существующего
  трекера (решение ниже).

## 5. Модули

### 5.0. `forbidden-lands-sheet` — лист персонажа (реализован)

Модуль `forbidden-lands-sheet` в разделе **«Запретные земли»** собран по
PDF-бланку, предоставленному пользователем: две страницы (лицевая и оборот),
фон — рендер страниц, поверх — поля.

**Лицевая сторона:** народ, профессия, имя, внешность (лицо/тело/одежда),
характеристики-трекеры (Телосложение, Ловкость, Разум, Эмпатия), состояния
(переохлаждение, жажда, недосыпание, голод), травмы, 16 навыков, гордость,
тёмная тайна, возраст, репутация, шлем/щит/броня, оружие, Воля, достоинства
с рангами, опыт.

**Оборот:** отношения, снаряжение и грузоподъёмность, скакун, запасы
(еда/вода/стрелы/факелы), заметки, монеты (серебро/золото/медь).

**Поведение:** у каждого клиента свой выбранный персонаж и свои правки
(`perClientSelection` + `mergeListKey="chars"`); окно использует
`CharacterSheetFrame` — масштаб 50–200% и изменяемый размер. Состояние —
`extensionState['forbidden-lands-sheet']` в формате
`{ currentId, chars: [{ id, fields }] }`.

Поля взяты из **AcroForm редактируемого PDF** (130 виджетов): текстовые,
числовые и выпадающие списки используют точные координаты исходного бланка.
Дополнительно: травмы, заметки, скакун, условия и **кружки-чекбоксы** —
25 «Опыта» (две колонки на мече) и 10 «Воли»; при включении заливаются
красным.

Термины листа — из предоставленного PDF (Телосложение, Ловкость, Разум,
Эмпатия; Меткость, Проворство, Влияние и т.д.). Фон страниц — из PDF
пользователя; для публичного распространения нужен собственный арт.

### 5.1. `fl-dice` — кубы Запретных земель (реализован, MVP)

Модуль `fl-dice` в разделе **«Запретные земли»**: пул белых/красных/чёрных
d6, дополнительные d8/d10/d12, модификатор, помощь, сложность, успехи и баны,
один риск (push), отправка результата в чат. Движок — `shared/utils/flDice.ts`;
UI — `shared/ui/panels/FlDicePanel.tsx`.

Правила, реализованные в движке:

- 6 на d6 — 1 успех;
- на d8/d10/d12: 6–7 — 1 успех, 8–9 — 2, 10–11 — 3, 12 — 4;
- 1 на белых/чёрных — бан; 1 на красных и d8/d10/d12 не бан и не фиксируется;
- риск перебрасывает все кубы, кроме 6; на красных, d8/d10/d12 — ещё и 1;
- 1 на белых после риска снижает атрибут и даёт Волю, 1 на чёрных ломает
  снаряжение.

Пока не сделано: автоматическое применение урона атрибутам/Воле/снаряжению
к листу (результат показывает последствия, но лист не меняет). Это следующий
шаг после стабилизации листа.

**Возможности:**

- Степперы: база / навык / снаряжение; дополнительные d8, d10 и d12.
- Модификатор (положительный/отрицательный), помощь (+1…+3),
  сложность (сколько успехов нужно).
- Бросок: группы кубов; на d8/d10/d12 несколько уменьшенных мечей на грани
  (1–4 успеха).
- Кнопка **«Рискнуть»**: один раз, перебрасывает все кубы, кроме 6; на
  красных, d8/d10/d12 — ещё и 1.
- Итог: успехи, баны по цветам, «нужно ещё N», успех/провал.
- Отправка результата в чат.
- Контекст броска: атрибут, навык, предмет, сложность — чтобы лист мог
  применить последствия к правильным полям.

**Предлагаемая модель:**

```ts
export type FlDieType = 'base' | 'skill' | 'gear' | 'd8' | 'd10' | 'd12'

export interface FlRollRequest {
  base: number
  skill: number
  gear: number
  modifier?: number
  help?: number
  difficulty?: number
  attribute?: 'strength' | 'agility' | 'wits' | 'empathy'
  skillId?: string
  gearItemId?: string
}

export interface FlDie {
  type: FlDieType
  value: number // 1..6
  negative?: boolean
}

export interface FlRollResult {
  dice: FlDie[]
  successes: number
  baseBanes: number
  skillBanes: number
  gearBanes: number
  pushed: boolean
  difficulty?: number
}
```

**Алгоритм:**

1. Собрать кубы: `base` белых, `skill + max(0, modifier) + help` красных,
   `gear` чёрных; при отрицательном модификаторе добавить минус-кубы.
2. Бросить d6; успехи = 6, баны = 1 по типам.
3. Риск: перебросить все кубы, кроме 6; на красных, d8/d10/d12 — ещё и 1.
4. Пересчитать успехи/баны; d8/d10/d12: 6–7 — 1, 8–9 — 2, 10–11 — 3, 12 — 4;
   `baseBanes` → урон и Воля, `gearBanes` → бонус −1.
5. Показать итог; при применении обновить персонажа.

**Крайние случаи:**

- push доступен один раз; повторно нельзя;
- если перебрасывать нечего — push недоступен;
- минус-кубы не могут дать успех, только вычесть;
- бонус снаряжения не уходит ниже 0; при 0 предмет сломан;
- атрибут не уходит ниже 0; при 0 персонаж «Сломлен»;
- Воля начисляется только за баны **после** push;
- сложность 0/не задана — просто показываем успехи.

**Визуал:** 2D-кубы с мечами/черепами, белые/красные/чёрные, с анимацией
встряхивания. 3D — потом, если захочется; кастомные грани d6 в текущем
3D-движке требуют текстур.

**Чат:**

```
🎲 Запретные земли: Сила + Ближний бой + Меч
Белые 3 · Красные 2 · Чёрные 2 → ⚔⚔ 2 успеха, ☠ 1 бан (база)
```

После push — отдельное сообщение с новым итогом.

### 5.2. `fl-sheet` — лист персонажа (P0)

Нативная панель с вкладками.

**Вкладки:**

1. **Основное**
   - атрибуты (текущее/максимум, черепа);
   - Воля;
   - состояния (сонный/голодный/жаждущий/замёрзший);
   - 16 навыков по четырём колонкам с кнопками броска.
2. **Бой**
   - оружие: название, хват, бонус, урон, дистанция, свойства;
   - броня и щит;
   - критические ранения;
   - быстрые действия (dodge/parry/shove/…).
3. **Снаряжение**
   - предметы, бонус кубов, расходники (supply dice), перегруз.
4. **Таланты**
   - название, ранг, описание.
5. **Биография**
   - род, профессия, возраст, гордость, тёмная тайна, репутация, опыт,
     внешность, заметки.

**Поведение:**

- Выбор персонажа, «＋ Новый», «Удалить» (с подтверждением).
- Автосохранение; общее состояние сессии.
- Кнопки броска у атрибута/навыка/оружия собирают пул и открывают
  `fl-dice` с контекстом.
- После push — «Применить» списывает урон, бонус снаряжения и добавляет Волю.
- Состояния и критические ранения можно отправить в чат.
- Игроки редактируют листы (как AZAG), если не решим иначе.

**Предлагаемая модель:**

```ts
export interface FlAttributeValue {
  value: number
  max: number
}

export interface FlWeapon {
  id: string
  name: string
  grip: '1h' | '2h' | 'unarmed'
  bonus: number
  damage: number
  range: string
  features: string[]
  equipped: boolean
}

export interface FlArmor {
  id: string
  name: string
  rating: number
  bodyPart: 'body' | 'head'
  equipped: boolean
}

export interface FlCharacter {
  id: string
  name: string
  kin: string
  profession: string
  age: string
  pride: string
  darkSecret: string
  reputation: number
  xp: number
  willpower: number
  attributes: Record<'strength' | 'agility' | 'wits' | 'empathy', FlAttributeValue>
  conditions: { sleepy: boolean; hungry: boolean; thirsty: boolean; cold: boolean }
  skills: Record<string, number>
  talents: Array<{ id: string; name: string; rank: number; description: string }>
  weapons: FlWeapon[]
  armors: FlArmor[]
  gear: Array<{ id: string; name: string; bonus: number; quantity: number }>
  criticalInjuries: Array<{ id: string; name: string; healingTime: string }>
}
```

### 5.3. `fl-initiative` — инициатива картами (P1)

- Колода 1–10, раздача без повторов.
- Порядок по возрастанию; текущий ход.
- Обмен картами в начале раунда.
- Новая раздача на раунд.
- Скрытые NPC и «Ход Мастера» для игроков.
- Отметки быстрого/медленного действия (опционально).
- Кнопки «Раздать», «Следующий», «Новый раунд», «Обменять».

Решение: **отдельный модуль**, чтобы не усложнять универсальный трекер
режимом колоды. Общий код бойцов можно переиспользовать позже.

### 5.4. `fl-journey` — путешествие (P2)

- Партия на гекс-карте.
- Активности по четвертям дня (Hike, Lead the Way, Keep Watch, Forage, Hunt,
  Fish, Make Camp, Rest, Sleep, Explore).
- Модификаторы местности/погоды, припасы/вода, ночлег.
- Броски активности и встречи — в чат.
- Общее состояние партии; роли участников.
- Таблицы встреч — только пользовательские, без копирования книг.

### 5.5. `fl-stronghold` — укрепление (P2)

- Здания, наймиты, материалы, зарплаты, доход/расход.
- Общий объект партии.
- Возможен позже, после путешествий.

### 5.6. Дополнительные идеи

- **FL-состояния на токенах**: сонный/голодный/жаждущий/замёрзший, «Сломлен»;
  расширить каталог состояний из модуля HP/AC.
- **Crit chat card**: критическое ранение отдельной карточкой в чат.
- **Party sheet**: общие припасы, роли, опыт, репутация.
- **Supply dice**: расходники как d8/d10/d12 с уменьшением при использовании.
- **Компендиум**: таланты, заклинания, снаряжение — только ввод пользователя.
- **Bestiary**: не делать из-за copyright; максимум — пустые карточки NPC.
- **3D-кубы FL**: позже; кастомные грани d6 потребуют текстур/шейдеров.

## 6. Приоритеты и оценка

| Модуль                  | Приоритет | Сложность | Зависимости           |
| ----------------------- | --------- | --------- | --------------------- |
| `fl-dice`               | P0        | S–M       | —                     |
| `fl-sheet`              | P0        | M         | `fl-dice` для бросков |
| Связка листа и кубов    | P0        | S         | оба                   |
| `fl-initiative`         | P1        | S–M       | —                     |
| `fl-journey`            | P2        | L         | партия, чат           |
| `fl-stronghold`         | P2        | M         | —                     |
| FL-состояния на токенах | P2        | S         | HP/AC-модуль          |

**Порядок:**

1. Движок `flDice` + панель `fl-dice` + чат.
2. Лист `fl-sheet` MVP: атрибуты, навыки, Воля, состояния, оружие/броня,
   био.
3. Связка: бросок из листа, контекст, применение урона/Воли.
4. Инициатива картами.
5. Путешествия и укрепление — по запросу.

## 7. Открытые вопросы

1. **Термины.** Свои русские названия или ждать официальную локализацию?
2. **Права.** Листы редактируют все (как AZAG) или только владелец/Мастер?
   Модели владения токенами у нас пока нет.
3. **Кубы.** 2D-символьные (рекомендуется) или 3D?
4. **Гордость.** Как именно d12 добавляется к броску — уточнить по книге,
   чтобы не автоматизировать неверно.
5. **Health/Resolve.** Нужен ли опциональный вариант вместо урона атрибутов?
6. **Инициатива.** Отдельный модуль или режим общего трекера?
7. **Путешествия.** Нужны ли в первой версии или достаточно листа и кубов?
8. **Контент.** Публиковать ли компендиум талантов/заклинаний с разрешения
   Free League (проверить Community License).

## 8. Предлагаемые решения (по умолчанию)

- Свои русские термины, близкие к официальным.
- Листы редактируют все участники (как в AZAG); позже — владельцы.
- 2D-кубы с мечами/черепами; 3D — отдельным этапом.
- `fl-initiative` — отдельный модуль.
- Путешествия и укрепление — после P0–P1.
- Никаких скопированных таблиц/арта; только механики и пользовательский ввод.

## 9. Definition of Done для `fl-dice` / `fl-sheet`

- `npm run typecheck`, `npm run lint`, сборка.
- Тесты движка: успехи, баны, push, урон, Воля, минус-кубы, границы.
- Тесты сохранения листа: несколько персонажей, независимый выбор у клиентов,
  слияние правок.
- Проверка чата: результат и push уходят всем.
- Скриншоты панели и листа.
- README/agent.md: новый раздел каталога и правила работы с FL.
