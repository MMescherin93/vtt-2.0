# Клинки во тьме — бланк команды

Модуль одного пустого PDF-бланка команды Blades in the Dark (две страницы) с
редактируемыми полями поверх PDF.

- PDF: `pdfs/empty.pdf`;
- просмотр и наложение полей: локальный PDF.js;
- строки и чекбоксы сгенерированы из геометрии пустого бланка;
- значения сохраняются локально (`bitd-crews-fields-v1`);
- окно использовать через `CharacterSheetFrame`.

Материал — бесплатный раздаточный PDF с rpgbook.ru; локальная копия для стола,
не для отдельной публикации.
