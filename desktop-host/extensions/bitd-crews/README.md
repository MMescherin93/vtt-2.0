# Клинки во тьме — бланки команд

Модуль выбора и просмотра PDF-бланков команд Blades in the Dark.
PDF лежат в `pdfs/`; просмотр — через локальный PDF.js (`../vendor/pdfjs`).

- 7 вариантов: пустой, Адепты, Бандиты, Барыги, Душегубы, Перевозчики, Тени;
- выбор запоминается в `localStorage` клиента;
- окно использовать через `CharacterSheetFrame`.

Материалы — бесплатные раздаточные PDF с rpgbook.ru; локальная копия для стола,
не для отдельной публикации.
