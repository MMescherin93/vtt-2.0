# Корни — лист персонажа

Лист персонажа для Root: The Roleplaying Game.

- несколько листов бродяг в одном модуле; у каждого клиента свой выбранный лист;
- имя, архетип, вид, местоимения, внешность, мотив, характер;
- Шарм, Хитрость, Сноровка, Удача, Мощь;
- Травмы, Истощение и Затраты — по пять отметок;
- репутация с Обитателями, Маркисой де Коте, Крылатыми династиями и Лесным союзом;
- ходы, связи, снаряжение;
- вопросы предыстории и заметки;
- кнопки броска 2d6 + характеристика с отправкой в чат.

Состояние общее для стола: Мастер и игроки видят все листы и могут их
редактировать (`playerWritable`). Данные лежат в
`extensionState['root-sheet']` в формате `{ version, currentId, chars }`;
выбранный лист — локальный для каждого клиента (`perClientSelection`), правки
разных листов объединяются (`mergeListKey="chars"`).
Окно открывается через `CharacterSheetFrame`.

Тексты ходов и архетипов не встроены: используйте свои книги/материалы.
