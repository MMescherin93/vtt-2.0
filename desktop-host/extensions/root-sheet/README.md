# Корни — лист персонажа

Лист персонажа для Root: The Roleplaying Game.

- имя, плейбук, вид, местоимения, внешность, стремление, натура;
- Обаяние, Хитрость, Ловкость, Удача, Мощь;
- Урон и Истощение;
- Репутация с фракциями;
- ходы, связи, снаряжение;
- вопросы предыстории и заметки;
- кнопки броска 2d6 + характеристика с отправкой в чат.

Значения сохраняются локально в `localStorage` (`root-sheet-v1`).
Окно открывается через `CharacterSheetFrame`.

Тексты ходов и плейбуков не встроены: используйте свои книги/материалы.
