# Агон — лист героя

Редактируемый лист персонажа по PDF-бланку «Агон» (Студия 101).
Фон — `sheet.png`; поверх него расположены поля.

- имя, эпитет, происхождение, род, покровитель, способность;
- четыре Домена и их кубики;
- Слава, Пафос, Агония, Судьба, Милость богов;
- обязательства, облик и особенности;
- подвиги и добыча, награды;
- вопросы о подвиге и добродетели.

Значения сохраняются локально в `localStorage` (`agon-sheet-fields-v1`).
Окно обязательно использовать через `CharacterSheetFrame`.

Бланк — материал пользователя; локальная копия для стола.
