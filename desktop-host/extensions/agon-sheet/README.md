# Агон — лист героя

Редактируемый лист персонажа по PDF-бланку «Агон» (Студия 101).
Фон — `sheet.png`; поверх него прозрачно наложены поля.

- несколько листов героев: создание, удаление, выбор у каждого клиента свой;
- название листа в списке и заголовке окна берётся из поля «Имя»;
- общее состояние сессии: правки видны Мастеру и всем игрокам, разные листы
  сливаются по `id`;
- имя, эпитет, «из рода», покровитель и способность;
- четыре Домена и выпадающие кубики `4 / 6 / 8 / 10 / 12`;
- Слава (40 клеток), рубежи Имени (6), Пафос, Агония, Судьба;
- Милость богов (24 ромба), узы с покровителем (2 ромба);
- обязательства, облик и особенности, подвиги и добыча, награды;
- портрет: весь большой круг кликабелен; изображение обрезается по кругу,
  сжимается до 512 px и хранится в общем состоянии.

- состояние: `com.agon.sheet/state`;
- права: редактирует любой участник (`playerWritable`);
- окно обязательно открывается через `CharacterSheetFrame`.

Бланк — материал пользователя; локальная копия для стола.
