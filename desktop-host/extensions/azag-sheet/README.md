# Лист персонажа AZAG

Редактируемый лист персонажа для игры **AZAG (Dank Dungeons)**. Сделан по
PDF-бланку `Лист AZAG А4.pdf`: фон — отрисованная страница, поверх неё
прозрачные поля ввода, повторяющие все поля PDF-формы.

## Как устроено

- `sheet.png` — страница PDF в высоком разрешении (3×).
- `fields.generated.js` — 61 поле формы (координаты, тип, многострочность),
  сгенерировано из PDF. Вручную не редактируется.
- `index.html`, `styles.css`, `app.js` — интерфейс и логика листа.
- `obr-shim.js` — адаптер Owlbear Rodeo SDK, общий для модулей VTT.

## Данные

Состояние хранится в сессии VTT под ключом `com.azag.sheet/state`:

```json
{ "currentId": "c_…", "chars": [{ "id": "c_…", "fields": { "chr name": "…" } }] }
```

Как и у листа «Тройки», у каждого пользователя свой выбранный лист, а правки
разных листов объединяются по `id`. Редактировать может любой участник.
