# Hero Kids — лист персонажа

Модуль для игры «Hero Kids — Маленькие герои»: лист героя и монстра по карточке
из книги, броски 3D-кубиков внутри листа, библиотека иконок и карточки
снаряжения.

## Роли

- **Мастер** создаёт и заполняет листы, отмечает урон и нокаут, выбирает навыки
  и предметы, загружает портреты, создаёт карточки снаряжения.
- **Игрок** видит только героев, не может менять лист; ему доступны броски
  пулов, проверки способностей, предметы и инициатива.
- Запись состояния разрешена только Мастеру (`playerWritable` не включён),
  сервер отклоняет `extension:update` от игрока.

## Управление

- Выбор листа — селектор в нижнем доке. Выбор запоминается локально у каждого
  клиента (`localStorage`, ключ `herokids-selected-v1`).
- `⚔ / 🏹 / ✨ / 🛡` — броски пулов. Клик по заполненному кубику на карточке
  тоже бросает.
- `🎯 Проверка` — 1 базовый к6 + пул + 1 за навык/предмет, сложность 4/5/6.
- Клик по иконке навыка в листе открывает проверку с этим навыком.
- `🎲 Инициатива` — 1к6.
- `✏️` — режим редактирования (имя, тексты, пулы по клику на кубики, портрет).
- `⚙` — настройки листа: имя, архетип, тип, здоровье, пулы, портрет,
  активное снаряжение.
- `📚` — библиотека навыков, предметов и способностей.
- `🗂` — карточки снаряжения.
- `⋯` — дублировать лист, отдых, полное лечение, удалить.
- Урон отмечается кликом по клеткам здоровья; порядок — справа налево.

## Режим монстра

Монстр — тот же лист с `kind: 'monster'`:

- фон без раздела «Инвентарь и навыки»;
- здоровье 1–4: «Нокаут», «Нокаут + Рана», как у героя или + «Ссадина»;
- библиотека навыков недоступна, предметы и способности можно добавлять;
- игроки монстров не видят.

## 3D-кубики

Движок `dice-box-threejs` берётся из соседнего модуля
`/extensions/dice3d/` (файл и текстуры не дублируются). Оверлей и математика
живут в `app.js`. Если WebGL или движок недоступны, автоматически включаются
2D-кубики с той же математикой. Результат уходит в чат сообщением вида
`🎲 Hero Kids · Костя · Ближняя атака (3к6): ...`.

## Состояние

Ключ — `com.herokids/state`:

```ts
{
  version: 1,
  currentId: string | null,
  chars: Array<{
    id, kind: 'hero' | 'monster', name, archetype, portrait,
    pools: { melee, ranged, magic, armor },   // 0..3
    healthMax: 1..4, damage, attack, action, ability,
    skills: string[], items: [{ id, count }], equipment: string | null
  }>,
  cards: Array<{
    id, title, kind: 'equipment' | 'item' | 'gift', art,
    flavor, effect, note, bonuses: { melee?, ranged?, magic?, armor? }
  }>
}
```

Состояние санитайзится при загрузке: длины строк, допустимые id иконок,
пулы 0–3, здоровье 1–4, до 24 листов и 60 карточек. Портреты и иллюстрации
сжимаются в браузере до 384 px JPEG.

## Разработка

Модуль можно открыть отдельно от VTT, он работает на `localStorage`:

- `?demo=1` — демо-герой;
- `?demo=monster` — демо-монстр;
- `?panel=cards|settings|library|check` — сразу открыть панель;
- `?roll=melee` — автоматический бросок (для проверки 3D).
