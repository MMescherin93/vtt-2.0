# Hero Kids — лист персонажа

Модуль для игры «Hero Kids — Маленькие герои»: лист героя и монстра по карточке
из книги, броски 3D-кубиков внутри листа, библиотека иконок и карточки
предметов с назначением героям.

## Роли

- **Мастер** создаёт и заполняет листы, отмечает урон и нокаут, выбирает навыки
  и предметы, загружает портреты и изображения карточек, создаёт карточки
  предметов и выдаёт их героям.
- **Игрок** видит только героев, не может менять лист; ему доступны броски
  пулов, проверки способностей, предметы, инициатива и «Библиотека» с выданными
  карточками.
- Запись состояния разрешена только Мастеру (`playerWritable` не включён),
  сервер отклоняет `extension:update` от игрока.

## Управление

- Выбор листа — селектор в нижнем доке. Выбор запоминается локально у каждого
  клиента (`localStorage`, ключ `herokids-selected-v1`).
- `⚔ / 🏹 / ✨ / 🛡` — броски пулов. Клик по яркому кубику на карточке
  тоже бросает.
- `🎯 Проверка` — 1 базовый к6 + пул + 1 за навык/предмет, сложность 4/5/6.
- Клик по иконке навыка в листе открывает проверку с этим навыком.
- `🎲 Инициатива` — 1к6.
- Кубики пулов: клик Мастера — яркий/тёмный; у игрока клик по яркому бросает пул.
- `⚙` — настройки листа: имя, архетип, тип, здоровье, пулы, два выпадающих
  списка для навыков и предметов, портрет.
- `📚` — добавить навыки, предметы и способности из книги.
- `📖 Предметы и навыки` — карточки предметов, выданные герою, и вкладка
  «Навыки и инвентарь» с описаниями и проверками. Доступна и игрокам.
- `⋯` — дублировать лист, отдых, полное лечение, удалить.
- Класс и имя — одна строка «Класс: Имя» над линией; у Мастера оба поля
  редактируются, у игрока только для чтения.
- Урон отмечается кликом по клеткам здоровья; порядок — справа налево.
- Два зелья всегда на листе: клик переключает «в наличии / потрачено»,
  размер как у кубика.
- Можно выбрать только один навык и один предмет; поля крупные, в один ряд.
- Клик по полю предмета/навыка у Мастера открывает список замены или снятия.

## Режим монстра

Монстр — тот же лист с `kind: 'monster'`:

- фон без раздела «Инвентарь и навыки»;
- здоровье 1–4: «Нокаут», «Нокаут + Рана», как у героя или + «Ссадина»;
- библиотека навыков недоступна, предметы и способности можно добавлять;
- игроки монстров не видят.

## Карточки предметов

- Мастер создаёт карточку, загружает **своё изображение** (без иконок из книги)
  и отмечает в блоке «Выдать героям», кому она доступна.
- Игрок видит в «Библиотеке» только выданные его текущему герою карточки.
- Карточка не занимает графу «Инвентарь и навыки» — это отдельная библиотека.
- Вкладка «Навыки и инвентарь» показывает навыки и предметы из книги с
  описаниями; клик по навыку запускает проверку.

## 3D-кубики

Движок `dice-box-threejs` берётся из соседнего модуля
`/extensions/dice3d/` (файл и текстуры не дублируются). Оверлей и математика
живут в `app.js`. Если WebGL или движок недоступны, автоматически включаются
2D-кубики с той же математикой. Результат уходит в чат сообщением вида
`🎲 Hero Kids · Костя · Ближняя атака (3к6): ...`.

## Состояние

Ключ — `com.herokids/state`:

```ts
{
  version: 1,
  currentId: string | null,
  chars: Array<{
    id, kind: 'hero' | 'monster', name, archetype, portrait,
    pools: { melee, ranged, magic, armor },   // 0..3
    healthMax: 1..4, // герой всегда 3, монстр задаётся 1..4
    damage, attack, action, ability,
    skills: string[], items: [{ id, count }],
    potions: [boolean, boolean]  // два зелья: true — в наличии
  }>,
  cards: Array<{
    id, title, kind: 'equipment' | 'item' | 'gift',
    art,                    // data:image/… — своя загрузка
    flavor, effect, note,
    assignedTo: string[]    // id листов, которым выдана карточка
  }>
}
```

Состояние санитайзится при загрузке: длины строк, допустимые id иконок,
пулы 0–3, здоровье 1–4, до 24 листов и 60 карточек. Портреты и изображения
карточек сжимаются в браузере до 384 px JPEG.

Старое поле `char.equipment` при загрузке мигрирует в `card.assignedTo`.

## Разработка

Модуль можно открыть отдельно от VTT, он работает на `localStorage`:

- `?demo=1` — демо-герой;
- `?demo=monster` — демо-монстр;
- `?edit=1` — сразу режим редактирования;
- `?panel=cards|skills|settings|library|check` — сразу открыть панель;
- `?inv=item|skill` — открыть выпадающий список добавления;
- `?used=1` — показать одно потраченное зелье;
- `?roll=melee` — автоматический бросок (для проверки 3D).
