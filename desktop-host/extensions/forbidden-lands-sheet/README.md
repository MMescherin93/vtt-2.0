# Запретные земли — лист персонажа

Интерактивный лист персонажа для Forbidden Lands, собранный по PDF-бланку,
предоставленному пользователем для личного стола.

- две страницы: лицевая и оборот;
- характеристики-трекеры, состояния, травмы;
- 16 навыков;
- гордость, тёмная тайна, возраст, репутация, опыт;
- шлем, щит, броня, оружие;
- Воля, достоинства и ранги;
- отношения, снаряжение, скакун, запасы, заметки, монеты;
- общее состояние в `extensionState['forbidden-lands-sheet']`:
  `{ currentId, chars: [{ id, fields }] }`;
- у каждого клиента свой выбранный персонаж, правки разных листов сливаются.

Окно листа использует общий `CharacterSheetFrame`: масштаб содержимого
50–200% и изменяемый размер окна.

Фон страниц — рендер предоставленного PDF. Не публиковать как самостоятельный
арт-пакет; для распространения нужен собственный фон.
